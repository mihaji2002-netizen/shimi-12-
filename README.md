# شیمی‌حدس

وب‌اپلیکیشن فارسی برای **حدس سوال‌به‌سوال امتحان نهایی شیمی دوازدهم** بر اساس:

- اسکلت پاسخبرگ ارسالی (۱۶ سوال / ۲۰ نمره + برچسب قسمت‌ها)
- الگوی آزمون‌های نهایی گذشته (۹۸ تا ۱۴۰۳)
- بارم‌بندی و محتوای کتاب شیمی ۳

## اجرا

```bash
npm install
npm run dev
```

ساخت نسخه نهایی:

```bash
npm run build
npm run preview
```

## امکانات

- ۱۶ ردیف قفل‌شده روی پاسخبرگ (نمره و قسمت‌ها)
- حدس محتوا برای هر ردیف با احتمال و دلیل
- پاسخبرگ احتمالی برای هر سوال
- رأی «محتمل / بعید» و جمع‌بندی پوشش فصل‌ها
