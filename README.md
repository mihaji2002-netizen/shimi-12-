# پیش‌بینی امتحان نهایی شیمی ۱۲ام

پیش‌بینی پاسخبرگ خالی امتحان نهایی شیمی دوازدهم — پپسینوژن

## لینک برای بچه‌ها

بعد از یک‌بار فعال‌کردن GitHub Pages، این لینک پایدار است:

**https://mihaji2002-netizen.github.io/shimi-12-/**

فعال‌سازی (فقط یک‌بار، ۳۰ ثانیه):
1. برو به [Settings → Pages](https://github.com/mihaji2002-netizen/shimi-12-/settings/pages)
2. Source را بگذار روی **Deploy from a branch**
3. Branch را بگذار روی **`gh-pages`** و فولدر **`/ (root)`**
4. Save بزن

ریپو: https://github.com/mihaji2002-netizen/shimi-12-

## توسعه محلی

```bash
npm install
npm run dev
```
