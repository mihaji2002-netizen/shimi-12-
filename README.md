# شیمی‌حدس

وب‌اپلیکیشن فارسی برای **حدس سوال‌به‌سوال امتحان نهایی شیمی دوازدهم** بر اساس:

- الگوی آزمون‌های نهایی گذشته (۹۸ تا ۱۴۰۳)
- بارم‌بندی رسمی کتاب شیمی ۳
- ساختار واقعی سوالات خرداد ۱۴۰۳

## اجرا

```bash
npm install
npm run dev
```

ساخت نسخه نهایی:

```bash
npm run build
npm run preview
```

## امکانات

- ۱۵ سوال پیش‌بینی‌شده با قالب واقعی امتحان نهایی
- نمایش احتمال، فصل، نمره و دلیل حدس
- پاسخبرگ احتمالی برای هر سوال
- رأی «محتمل / بعید» و جمع‌بندی پوشش فصل‌ها
